## What I do

- Hunt bugs in **business logic and access control**: auth flows, state machines, privilege edges
- Analyse JavaScript at scale for URLs and leaked secrets
- Build Android tooling for security work and for everyday coding
- Write up findings clearly and share methodologies on Medium

## Projects

| Project | What it is |
| --- | --- |
| [SastraCode](https://github.com/vikas0vks/sastracode-builds) | A coding assistant for Android. Reads and edits projects, runs commands, and manages long tasks on-device. Installable builds are public. |
| [JSNinja](https://github.com/vikas0vks/JSNinja) | Extracts URLs and secrets from JavaScript files for pentesters and bug bounty hunters. |
