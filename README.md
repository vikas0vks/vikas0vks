## About

I research web application security and hunt bugs for a living — with a focus on **business logic and
access control flaws**, the classes of bugs that hide in how an application is meant to work.

- Hall of Fame recognitions from **Google** and **OZiva**
- Contributions on platforms such as HackerOne
- I enjoy the full loop: recon, finding the flaw, writing it up, and building the tool that finds the
  next one faster

## What I build

| Project | What it does |
| --- | --- |
| [SastraCode](https://github.com/vikas0vks/sastracode-builds) | A coding assistant for Android — reads and edits your projects, runs commands, and manages long tasks on-device. Installable builds are published here (source is private). |
| [JSNinja](https://github.com/vikas0vks/JSNinja) | Extracts URLs and sensitive secrets from JavaScript files. Made for penetration testers and bug bounty hunters who analyse JS at scale. |
| [Pentabar](https://github.com/vikas0vks/pentabar) | A web security and penetration testing toolkit for Android. |
| Research notes | I curate [a methodology list on Medium](https://medium.com/@vikas0vks/list/methodology-3aa7c4183b7b) — platforms, tools, techniques and resources for learning bug bounty hunting. |

More work is in private development: Android applications, security tooling, and a zero-knowledge
password manager (Rust core with WebAssembly and Cloudflare Workers).

## Writing
